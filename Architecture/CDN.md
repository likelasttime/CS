### CDN(Content Delivery Network)
- 전 세계에 분산된 서버 네트워크를 통해 사용자에게 콘텐츠를 빠르게 제공하는 시스템
- 원본 서버(Origin Server): 실제 콘텐츠가 저장된 메인 서버
- 엣지 서버(Edge Server): 전세계 곳곳에 분산된 캐시 서버
- 사용자가 콘텐츠를 요청하면 가장 가까운 엣지 서버가 응답한다.
- 엣지 서버에 콘텐츠가 없으면 원본 서버에서 가져와서 캐싱한다.
- 빠른 속도: 사용자와 가까운 서버에서 전달하여 지연 시간(latency) 감소
- 서버 부하 감소: 원본 서버 대신 엣지 서버가 트래픽 처리
- 안정성 향상: 한 서버가 다운되어도 다른 엣지 서버가 서비스 제공
- 대역폭 비용 절감: 원본 서버의 트래픽 감소로 비용 절감
- 글로벌 서비스: 전 세계 어디서든 빠른 속도 제공
- 이미지, 동영상, CSS, JavaScript 등 정적 파일, 자주 변경되지 않는 콘텐츠를 주로 캐싱한다.
- Cloudflare, AWS CloudFront, Akamai 같은 CDN 서버스를 많이 사용한다.
- 동영상 스트리밍, 게임 다운로드, 이커머스 사이트처럼 대용량 파일을 다루거나 전 세계 사용자를 상대하는 서비스에서는 필수다.

### 프록시(Proxy)
- 클라이언트와 서버 사이에서 중개자 역할을 하는 서버
- 클라이언트가 직접 서버에 접속하지 않고 프록시를 거쳐서 접속한다.
- 익명성 보장: 클라이언트의 IP를 숨긴다. 서버는 프록시의 IP만 본다.
- 접근 제어: 특정 사이트를 차단한다.
- 캐싱: 자주 요청하는 데이터를 저장해서 속도를 향상한다.
- 우회 접근: 특정 지역에서 차단된 사이트에 접근한다.

<br>

### 리버스 프록시
- 서버 앞에 위치하며 서버를 대신해서 클라이언트의 요청을 받는다.
- 로드 밸런싱: 여러 서버에 요청을 분산한다.
- 보안 강화: 실제 서버의 IP를 숨긴다.
- SSL 종료: HTTPS 처리를 프록시에서 담당한다.
- 캐싱: 정적 파일을 캐싱해서 서버 부하를 감소한다.
- 압축: 응답을 압축해서 전송한다.
- Nginx, HAProxy, Apache가 리버스 프록시로 많이 사용된다.

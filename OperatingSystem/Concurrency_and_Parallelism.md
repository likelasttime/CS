### 동시성(Concurrency)
- 여러 작업을 번갈아가며 처리하는 것
- 실제로 한 번에 하나씩 처리하지만, 빠르게 전환하기 때문에 동시에 실행되는 것처럼 보인다.
- 단일 코어에서도 가능하다.
- 컨텍스트 스위칭(작업 전환)이 발생한다.
- I/O 대기 시간 활용(파일 읽기, 네트워크 요청 등)
- 응답성 향상(한 작업이 멈춰도 다른 작업 진행)

<br>

### 병렬성(Parallelism)
- 여러 작업을 동시에 처리하는 것
- 멀티 코어 필수(CPU가 2개 이상)
- 처리 속도 향상(계산량이 많은 작업)
- 작업 간 데이터 공유를 조심해야 한다.

- 클라이언트와 서버 간에 양방향 실시간 통신을 가능하게 하는 프로토콜
- 한 번 연결하면 계속 연결 상태를 유지하면서 데이터를 주고받을 수 있다.
- 실시간 채팅(카카오톡, 슬랙 같은 메신저), 실시간 알림(새 메시지, 좋아요 알림 등), 게임(멀티플레이어 게임의 실시간 상태 동기화), 주식/코인 시세(실시간으로 변동하는 가격 정보), 협업 도구(Google docs처럼 여러 명이 동시에 편집)에 사용되는 기술이다.
- 연결을 계속 유지하기 때문에 서버 리소스를 많이 사용한다.
- 실시간성이 중요하지 않다면 HTTP 풀링이나 Server-Sent-Events(SSE)와 같은 대안을 고려할 수 있다.

<br>

|HTTP|WebSocket|
|-----|--------|
|클라이언트가 요청해야만 서버가 응답하는 단방향|연결 유지 후 서버/클라이언트 양쪽 모두 언제든지 데이터 전송 가능한 양방향|

<br>

#### WebSocket의 동작 방식
1️⃣ 핸드 쉐이크: HTTP로 연결 요청 후 WebSocket 프로토콜로 업그레이드
<br>
2️⃣ 연결 유지: TCP 연결을 계속 유지하면서 양방향 통신
<br>
3️⃣ 메시지 교환: 서버와 클라이언트가 자유롭게 메시지 전송
<br>
4️⃣ 연결 종료: 둘 중 하나가 연결을 닫을 때까지 유지

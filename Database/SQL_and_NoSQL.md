### SQL 데이터베이스
- 관계형 데이터베이스(RDBMS)
- 스키마에 따라 데이터를 행과 열로 구성된 테이블에 저장
- 데이터 구조가 명확하고 정합성이 중요할 때 사용
- ex) 은행 시스템, 사원 관리 시스템

<br>

### NoSQL 데이터베이스
- 정해진 틀 없이 자유로운 형태로 데이터를 저장
- 문서, 그래프, 키-값 등 다양한 방식으로 데이터를 저장
- 데이터 구조가 자주 바뀌거나 급격하게 늘어나는 상황에 유연하게 대처
- SNS 게시물이나 로그 데이터처럼 형식이 다양하고 양이 많은 비정형 데이터를 다룰 때 주로 사용

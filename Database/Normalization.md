### 정규화
|유형|의미|
|---|----|
|제1정규형|테이블의 컬럼이 원자 값을 가지도록 나누기|
|제2정규형|제1정규형을 만족하고, 기본키가 아닌 속성이 기본키에 완전 함수 종속(기본키의 부분집합이 다른 값을 결정하지 않음)이 되도록 나누기|
|제3정규형|제2정규형을 만족하고, 이행적 함수 종속(A -> B, B -> C일때 A -> C가 성립)을 없애도록 나누기|

<br>

### 제1정규형
- 쉽게 생각하면 한 칸에 하나의 데이터만 저장하는 것
#### Before
| 고객ID | 고객명 | 전화번호                         |
| ---- | --- | ---------------------------- |
| 1    | 김철수 | 010-1234-5678, 010-9999-8888 |
| 2    | 이영희 | 010-1111-2222                |

#### After
| 고객ID | 고객명 | 전화번호          |
| ---- | --- | ------------- |
| 1    | 김철수 | 010-1234-5678 |
| 1    | 김철수 | 010-9999-8888 |
| 2    | 이영희 | 010-1111-2222 |

<br>

### 제2정규형
- 학생이름은 학번에만 종속된다.
- 과목명은 과목코드에만 종속된다.
#### Before
| 학번(StudentID) | 과목코드(CourseID) | 학생이름(StudentName) | 과목명(CourseName) | 성적(Grade) |
| ------------- | -------------- | ----------------- | --------------- | --------- |
| 1001          | CS101          | 김철수               | 자료구조            | A         |
| 1001          | MA101          | 김철수               | 선형대수            | B+        |
| 1002          | CS101          | 이영희               | 자료구조            | B0        |

#### After
- 세 테이블로 나누었다.
  
| 학번(StudentID) | 학생이름(StudentName) |
| ------------- | ----------------- |
| 1001          | 김철수               |
| 1002          | 이영희               |

<br>

| 과목코드(CourseID) | 과목명(CourseName) |
| -------------- | --------------- |
| CS101          | 자료구조            |
| MA101          | 선형대수            |

<br>

| 학번(StudentID) | 과목코드(CourseID) | 성적(Grade) |
| ------------- | -------------- | --------- |
| 1001          | CS101          | A         |
| 1001          | MA101          | B+        |
| 1002          | CS101          | B0        |

<br>

### 제3정규형
#### Before
- 기본키는 EmpID
- DeptName은 DeptID에 종속됨
- EmpID → DeptID → DeptName이므로 DeptName은 EmpID에 이행적으로 종속됨

| 사원ID(EmpID) | 부서ID(DeptID) | 부서이름(DeptName) | 사원명(EmpName) |
| ----------- | ------------ | -------------- | ------------ |
| 101         | D1           | 영업부            | 김철수          |
| 102         | D2           | 개발부            | 이영희          |
| 103         | D1           | 영업부            | 박지성          |

#### After
| 사원ID(EmpID) | 사원명(EmpName) | 부서ID(DeptID) |
| ----------- | ------------ | ------------ |
| 101         | 김철수          | D1           |
| 102         | 이영희          | D2           |
| 103         | 박지성          | D1           |

<br>

| 부서ID(DeptID) | 부서이름(DeptName) |
| ------------ | -------------- |
| D1           | 영업부            |
| D2           | 개발부            |
